# Documentação da organização

Este diretório está reservado para decisões e guias compartilhados entre os
repositórios da Code Empire Tecnologias.

Conteúdos candidatos:

- arquitetura e ADRs transversais;
- padrões de API e versionamento;
- segurança, privacidade e resposta a incidentes;
- estratégia de branches, releases e Conventional Commits;
- observabilidade e operação;
- onboarding de desenvolvimento.

Documentações específicas de um produto devem continuar no repositório do
produto e ser apenas referenciadas daqui.
